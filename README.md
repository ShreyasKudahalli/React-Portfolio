# React Portfolio

This repository contains a modern personal portfolio website for Shreyas K, built with React and Vite. The project is designed to showcase technical skills, projects, education, coding activity, and contact information in a polished one-page experience.

## Project objective

The portfolio serves as a digital resume and personal brand landing page. It highlights:

- Professional introduction and background
- Core technical skills
- Featured projects and achievements
- Educational background
- Coding profiles and public work
- Contact and communication details

## Repository layout

- `Frontend/` - main React application and static assets
- `Backend/` - reserved for future API or backend services
- `docs/` - complete project documentation and operational guidance

## Technology stack

- React 19
- Vite
- JavaScript
- Tailwind CSS
- Lucide icons
- React Icons

## Quick start

1. Open the frontend directory:
   ```bash
   cd Frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build the app for production:
   ```bash
   npm run build
   ```

# Frontend portfolio app

This is the frontend application for the personal portfolio website.

## Stack

- React 19
- Vite
- Tailwind CSS
- Lucide React
- React Icons

## Project purpose

This app presents the developer's portfolio in a polished, responsive single-page layout. It includes sections for introduction, skills, education, projects, coding profiles, and contact details.

## Commands

Install dependencies:

```bash
npm install
```

Start local development server:

```bash
npm run dev
```

Build project for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Folder overview

- `src/App.jsx` - root page composition
- `src/layout/` - navigation and layout shell
- `src/components/` - reusable UI pieces
- `src/sections/` - content sections
- `public/` - static assets and downloadable resume

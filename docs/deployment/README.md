# Deployment and operations

## Local development

From the repository root:

```bash
cd Frontend
npm install
npm run dev
```

This starts the Vite development server and serves the portfolio locally.

## Production build

Generate a production build with:

```bash
cd Frontend
npm run build
```

The build output is generated by Vite and can be deployed as static files.

## Recommended hosting options

### Vercel

This project is well suited for Vercel because it supports Vite-based React projects with simple deployment steps.

Recommended process:

1. Push the repository to GitHub
2. Import the project into Vercel
3. Set the root directory to `Frontend`
4. Use the default build command and output directory

### Netlify

Netlify also works well for this static portfolio site. Upload or connect the repo and configure the frontend folder as the app root.

## Asset handling

Static files such as profile images, project previews, and the resume PDF should remain under `Frontend/public/` to keep paths stable after deployment.

## Environment variables

At the moment, no environment variables are required for the frontend. If a backend is introduced later, documentation should be added for:

- contact email credentials
- API base URLs
- auth variables
- deployment environment configuration

## Maintenance recommendations

- Keep the resume file updated in `Frontend/public/Resume.pdf`
- Update portfolio project entries as work changes
- Verify page responsiveness before deployment
- Run a production build before marking the site live

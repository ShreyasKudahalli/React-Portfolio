# Project documentation

This directory contains the primary documentation for the portfolio project. The docs are organized by concern so contributors can quickly find guidance for architecture, frontend details, backend planning, and deployment.

## Documentation index

- [Overview](./overview/README.md) - project purpose, goals, and architecture summary
- [Frontend](./frontend/README.md) - React application structure, components, and styling approach
- [Backend](./backend/README.md) - current backend state and recommended future services
- [Deployment](./deployment/README.md) - running locally, building, and shipping for production

## Intended use

These documents are meant to help:

- new developers understand the project quickly
- designers and stakeholders review the portfolio structure
- future contributors extend the app without breaking the current layout
- maintainers prepare deployment and hosting changes

## Project summary

The application is a single-page portfolio website built with React. It is intentionally focused on presentation and accessibility, offering a clean and professional visual identity with sections for personal information, technical capability, project work, and ways to contact the owner.
